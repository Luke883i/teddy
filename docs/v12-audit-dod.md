# Teddy V12 — audit and motion/appearance DoD (13 October 2026)

## Epistemic baseline
Main branch inspection establishes articulated geometry, a WebGL2 shader with procedural fuzz, Canvas2D fallback, thirteen bounded primitive motions, a grounded world-space movement engine and semantic routing. These mechanisms alone **do not prove** physically plausible animation, convincing plush texture or appealing frames. Prior 1M/10M state sweeps are synthetic numerical contracts, not browser image validation.

## Root cause and WIP
- 13 primitive motions are not a reusable expressive motion library.
- Surface fuzz is high-frequency procedural shader noise, not a validated continuous plush textile material; arms remain separate intersecting volumes.
- Grounding uses a bounded corrective contact point, not IK, friction, foot locking or collision dynamics.
- No golden video comparison, human appeal panel, multi-angle motion-grade baseline or objective image/video artifacts.
- TTS/ASR deployment and native availability are separate from the renderer.
- Existing draft PRs excluded by explicit user instruction.

## Delivered scope
30 named standard **macro routines** assembled from the existing 13 primitives; 2 complex choreographies, dance and iconic asymmetric Lightning Bolt. They are NOT thirty new skeletal primitives or thirty motion-captured animations. Choreographies expand to bounded, validated native intents; atomic queue admission; no evaluated model code. Lightning Bolt adds a native compound arm/leg/head pose, phased by existing MotionEngine. Every choreography must pass invariant checks at frame-by-frame simulation.

## Release DoD — not yet satisfied
1. **Character identity:** silhouette landmark tolerances defined against approved front, 3/4, side and back reference images; recognizable character in all four views.
2. **Pelt:** stitched-looking uniform fur microstructure tied to local tangent/UV coordinates, consistent texel density, body-specific roughness, no swimming under animation; clean ear/muzzle/paw material boundaries.
3. **Kinematics:** 30 distinguishable, intentional movements (not merely 30 differently named macros), plus dance and Lightning Bolt; key-pose timestamps, easing and transitions, graceful idle/recovery; no pop/discontinuity under frame stepping or interruption.
4. **Lightning Bolt:** one extended arm diagonal up, opposite arm crossing body, head facing gesture, asymmetrical grounded leg stance. Reference-based approval required; no claim of actual likeness certification.
5. **Scene:** physically coherent floor, shadows tracking planted feet, correct opacity/depth ordering, no floating seams.
6. **Metrics:** screen-space foot sliding < 3 pixels at 1080p in planted frames, no visible mesh penetration or limb detachment, no nonfinite transforms, no sequence past 8 queued intents; target 60fps p95 desktop reference GPU (hardware to be declared).
7. **Proof:** same final commit green Node test suite + deterministic mutation/state-space checks, headless WebGL screenshot + 30fps video clips for all 32 routines in front and 3/4 views, side-by-side visual review, manual scoring for recognizability >= 4/5 and pleasantness >= 4/5 with predefined raters and reference assets.
8. **Fallback:** Canvas2D honors reduced motion and reports feature difference; no false claim of parity with full articulated WebGL.
9. **Runtime:** local fresh-install and actual physical speech chain validated separately, with auditable artifacts.

## Semantic search / falsification
100,000 possible textual permutations are not automatically independent mutations or evidence of novelty. Only a reproducible tool performing an actual 100k-case run with inputs, seed, killed/surviving mutants, novelty counters and final hash may claim 100k executed mutations. This PR includes focused deterministic falsification tests but **does not claim a 100k run**.
