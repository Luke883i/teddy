# v0.7 verification contract

The v0.7 pull request is accepted only when all of these independent boundaries are green on the current head:

- the historical `ci` runtime job on Node 24, including legacy security, persistence, Realtime, presence, morphology and anatomy regressions;
- the historical authenticated container persistence job;
- the `local-v7` physical runtime job, including real child-process cancellation/output bounds and a loopback HTTP round trip;
- regeneration of exactly 1,000,000 deterministic semantic mutation identities (250,000 typical, 250,000 atypical, 250,000 challenging, 250,000 adversarial) with zero survivors and zero unsafe outcomes.

The mutation campaign is a contract-level falsification harness. It does not represent one million paid model sessions or one million AST rewrites. Native ASR/LLM/TTS quality and model-weight latency remain outside this PR until a pinned, licensed, multi-platform artifact manifest is committed and exercised.

A CI failure is treated as a falsifier: the pull request is mutated, the current head changes, and all acceptance jobs must run again on that new head before the PR is considered green.
