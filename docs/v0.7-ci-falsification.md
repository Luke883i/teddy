# v0.7 CI falsification log

The pull request was intentionally kept mutable until its current head satisfied both the historical and v0.7-specific gates.

1. The first v0.7 run exposed a brittle byte-for-byte mutation-report snapshot check. The campaign itself regenerated one million identities with zero survivors; the gate was corrected to validate regenerated totals, survivors and unsafe outcomes instead of treating an output snapshot as the invariant.
2. The historical runtime contract and v0.3 audit extracted the server version only from an inline object literal. v0.7 centralizes it in `const VERSION`; both regression readers were updated to verify package/server alignment without requiring the old syntax.
3. The v0.4 presence simulator legitimately changes its `sourceDigest` when the Web Audio implementation changes. CI now regenerates that source-derived report and validates scenario totals, zero unsafe outcomes, zero mutation survivors, zero missing capabilities, and valid source/campaign digests rather than requiring the pre-v0.7 audio snapshot.

No failure was waived: each obsolete assertion was replaced by a semantic invariant and the full current-head workflows are rerun after the mutation.
