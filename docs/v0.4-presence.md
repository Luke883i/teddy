# Teddy v0.4 — realtime presence DoD

This slice treats Teddy as a realtime character rather than a collection of primitives. The target is believable plush anatomy, expressive but bounded motion, speech-correlated articulation and graceful degradation without adding runtime dependencies.

## Visual / modeling

- [x] plush archetype contains at least 45 semantic parts and 9 articulated transform groups
- [x] face contains cheeks, dual muzzle lobes, nose bridge, eyes/catchlights, expressive brows and inset ears
- [x] mouth has at least five visible layers: upper lips, cavity, lower lip and tongue
- [x] arms are segmented into shoulder, forearm and hand; feet retain pads/toe landmarks
- [x] camera fits horizontal and vertical bounds independently, including needle portrait and ultrawide viewports
- [x] WebGL fur variation is evaluated in local/object coordinates so it does not swim across moving geometry
- [x] view-dependent lighting uses the actual adaptive camera position
- [x] Canvas2D degradation uses the same expression pose for eyes, brows, mouth, ears and articulated arm energy

## Expression / temporal behavior

- [x] a bounded expression rig owns jaw, lip shape, brows, squint, ears, head motion, shoulders, gestures and blink
- [x] pose smoothing is time-based rather than frame-count based and stays close across 30/60/144 Hz
- [x] blink timing is deterministic for tests but non-periodic in cadence
- [x] pointer/head tracking is clamped and smoothed by the rig instead of snapping transforms directly
- [x] reduced-motion suppresses decorative movement while preserving speech articulation and communication cues
- [x] listening, thinking, speaking, concerned and idle modes converge without a permanently stuck pose
- [x] silence releases the jaw below 0.03 in roughly 300 ms in the deterministic rig test

## Voice correlation / fluency

- [x] remote audio analysis combines time-domain RMS/peak with low/mid/high spectral energy
- [x] adaptive noise-floor gating prevents steady background hum from permanently opening the mouth
- [x] spectral brightness shapes wide/rounded articulation while onset/plosive proxies drive brief gesture energy
- [x] all voice features are finite and bounded even under hostile/non-finite synthetic input
- [x] configured output gain of exactly zero remains truly muted
- [x] spoken instructions request natural cadence, syntactic pauses and expressive intonation while avoiding read-aloud list/markdown behavior
- [x] interruption guidance avoids unnecessarily restarting an interrupted phrase

## Verification

- [x] pure tests cover anatomy, dual-axis camera fit, rig bounds, frame-rate invariance, blink scheduling, jaw release, noise adaptation, spectral proxies, clipping, mute semantics and renderer contracts
- [x] deterministic presence saturation evaluates 1,000,000 viewport, 1,000,000 voice, 1,000,000 temporal, 1,000,000 lifecycle and 1,000,000 dynamic-framing scenarios
- [x] ten critical capabilities receive 100,000 mutation identities each
- [x] total v0.4 campaign: 6,000,000 deterministic identities, zero critical unsafe outcomes and zero critical mutation survivors
- [x] CI regenerates `docs/presence-v4-report.json` and fails if committed evidence is stale
- [x] inherited v0.1/v0.2/v0.3 runtime/security/container gates remain enabled

The saturation campaign is synthetic design/fault exploration. It is not a claim of six million physical browsers or OpenAI sessions. Real Node HTTP, persistence, Realtime error semantics and container behavior remain separate CI gates.
