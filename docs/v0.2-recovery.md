# Teddy v0.2 — visual and connection recovery DoD

This slice responds to two observed product failures: the v0.1 procedural body did not read as an archetypal teddy bear, and an upstream HTTP 429 was collapsed into a generic “connection failed” alert.

## Visual DoD

- [x] Teddy is represented by semantic parts, not anonymous draw-order spheres.
- [x] Head, muzzle, eyes, catchlights, brows, mouth and ears share a head transform.
- [x] Bilateral ear, eye, arm, leg and paw landmarks are explicitly paired.
- [x] Inner ears, protruding muzzle, triangular nose, belly and four paw pads are present.
- [x] At least three 3D primitive families are used: sphere, box and triangular prism.
- [x] Non-uniformly scaled meshes use a normal matrix instead of directly multiplying normals by the model matrix.
- [x] Fur receives subtle procedural micro-variation without a texture dependency.
- [x] Warm key, cool fill, hemisphere ambient, rim and controlled specular separate facial volumes.
- [x] Camera distance is derived from archetype bounds; expected vertical occupancy is 52–62% across supported aspect classes.
- [x] The screenshot-like 1790×864 viewport and representative portrait/desktop viewports satisfy the framing invariant.
- [x] WebGL context loss degrades to a 2D bear that preserves the same face/ear/muzzle/paw landmarks.
- [x] `prefers-reduced-motion` continues to reduce idle animation rather than removing identity cues.

## Realtime/recovery DoD

- [x] 401, 403, 429, 5xx, timeout, microphone and WebRTC failures have distinct public semantics.
- [x] Upstream error bodies are not forwarded wholesale to the browser.
- [x] Safe diagnostic fields are retained: status, kind, upstream code and request ID.
- [x] `Retry-After` numeric and HTTP-date forms are bounded and normalized.
- [x] 429 produces an inline explanation, not a blocking `alert()`.
- [x] Rate-limit cooldown suppresses repeated upstream call creation attempts.
- [x] Quota failures do not suggest blind automatic retry.
- [x] Replacing/removing an API key clears local cooldown state.
- [x] WebRTC connection establishment has a finite timeout after SDP answer application.
- [x] Failed pre-connect attempts do not create durable empty conversations.
- [x] Last typed voice failure is available in Diagnostics.

## Verification DoD

- [x] Pure unit tests cover archetype metrics, camera fit, error classification, retry parsing, cooldown and UI guidance.
- [x] Static contract test forbids browser `alert()` and requires scene-graph/primitive landmarks.
- [x] Node 24 CI starts a real Teddy process against a local mock Realtime upstream returning `429 + Retry-After`.
- [x] That smoke verifies the second immediate connection attempt is absorbed locally and does not hit the mock upstream.
- [x] 1,000,000 deterministic holistic E2E design/fault scenarios complete with zero critical unsafe outcomes.
- [x] 100,000 visual, 100,000 connection and 100,000 session mutations complete with zero critical survivors.

The million-case campaign is deterministic synthetic fault-space exploration, not a claim of one million physical browsers or paid OpenAI calls. Physical runtime/process and 429 semantics are separately exercised by CI.
