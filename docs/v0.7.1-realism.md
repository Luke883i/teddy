# Teddy v0.7.1 — real-like continuity refinement

This slice is anchored to supplied runtime captures, not to an abstract teddy-bear ideal. Teddy is recognizable; the remaining failure class is assembled-body continuity and depth: detached-looking joints, a plate-like belly, distal-leg Z discontinuities, facial accents that can read as decals, and a contact shadow that does not follow world motion.

## Epistemic runtime slices

1. **E1 — frontal morphology.** Preserve the v5/v6 skull, eye/nose triangle and muzzle identity while reducing detail dominance.
2. **E2 — plush continuity.** Keep the existing articulated hierarchy and refinement wrapper; taper joints and smooth distal-leg depth rather than introducing a second mesh/rig.
3. **E3 — depth bands.** Model the belly as a shallow conforming cap; align shin/ankle/foot/pad depth; recess inner ears while keeping eyes and brows surface-attached.
4. **E4 — microexpression finish.** Reuse existing `ExpressionRig` channels (`smile`, `wide`, `round`, `blink`, `squint`) in the renderer. No second expression state machine is added.
5. **E5 — world grounding.** The contact shadow follows bounded world X/Z/yaw and tightens/fades while airborne. A nod rotates the complete head subtree, including jaw and ear groups.
6. **E6 — falsification.** The existing 10,000,000 + M+100 realism campaign remains the primary numerical gate and now also rejects configured runtime depth-band failures.

## Depth closure

The depth finish is implemented inside `web/teddy/refinement-v7.js`, `web/teddy/render.js` and `web/teddy/movement-v8.js` only.

Current deterministic metrics from `tools/refine-realism-v7.mjs --full`:

- belly front delta vs torso: ~0.0151; shallow projected volume rather than a thin plate;
- shin → ankle front-depth jump: ~0.0717;
- ankle → foot: ~0.2159;
- foot → pad: ~0.0139;
- inner-ear/outer-ear width ratio: ~0.489 with ~0.0132 front recess;
- eye aspect: ~1.149 and ~0.0073 surface projection;
- brow/eye width ratio: ~0.759 and ~0.0052 surface projection, with ~0.0214 embed into the skull surface.

The WebGL normal matrix is inverse-transpose correct for non-uniformly scaled ellipsoids/capsules. This matters because most Teddy primitives use different X/Y/Z scales.

## Microexpression closure

The renderer now consumes channels the rig already owned. Smile changes lip rotation and lift, `wide`/`round` reshape the visible mouth while preserving Z, and catchlights collapse with blink/squint instead of floating over closed eyes. Local full saturation evaluated 1,000,000 deterministic rig/renderer states with zero non-finite transforms, asymmetry, depth drift, floating catchlights or lip overflow.

## Saturation semantics

`tools/refine-realism-v7.mjs --full` evaluates exactly 10,000,000 deterministic parameter identities and then M+100 compound falsifications. The committed report also records runtime depth-band metrics and requires `depthRuntimeViolations=[]`.

This is numerical/state-space evidence, not ten million browser screenshots. A physical WebGL golden-image/video gate remains an independent future falsifier; the local container used for this refinement cannot initialize a reliable headless GL backend, so no second software renderer was introduced to fake that evidence.
