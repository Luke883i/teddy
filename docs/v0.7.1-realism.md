# Teddy v0.7.1 — real-like continuity refinement

This slice is anchored to the supplied frontal runtime capture, not to an abstract teddy-bear ideal. The image shows a recognizable Teddy whose remaining failure is assembled-body continuity: detached-looking shoulders, cylindrical arms, stacked leg joints, oversized frontal belly, plate-like feet and a mechanically layered mouth.

## Epistemic runtime slices

1. **E1 — frontal morphology.** Reduce belly dominance and foot width while preserving the v5/v6 head, eye/nose triangle and muzzle identity.
2. **E2 — plush continuity.** Inset shoulders and taper shoulder/elbow/wrist plus hip/knee/ankle transitions so the silhouette reads as stuffed anatomy rather than cylinders connected by balls.
3. **E3 — facial cleanup.** Reduce mouth-stack thickness while retaining jaw-driven speech projection.
4. **E4 — basic articulated actions.** Add bounded whole-chain raising of either arm, lifting of either leg and a root jump. Child joints receive the same pivot transform so limbs do not detach during the action.
5. **E5 — falsification.** Search 10,000,000 deterministic numerical identities over twelve independent parameters, then attack compound failure classes in an M+100 novelty window.

## Parameter model

The runtime refinement is isolated in `web/teddy/refinement-v7.js`. It wraps the stable v6 renderer rather than reopening shaders, voice coupling, persistence or provider code. The principal parameters are shoulder inset, limb width/taper, belly width/height, hip/knee scale, foot width/depth, muzzle vertical scale and bounded action amplitudes.

`tools/refine-realism-v7.mjs --full` evaluates exactly 10,000,000 deterministic parameter identities. Hard plausibility intervals are defined independently from the chosen runtime constants. Cross-constraints penalize elbow-over-arm width, plate-like feet and belly width/height imbalance. M+100 then attacks compound continuity/action families.

This campaign is numerical falsification, not ten million browser screenshots. A real WebGL browser golden-image/video gate remains the next independent evidence layer and should not be conflated with this result.
