# Teddy v0.7 local-first

Teddy v0.7 makes the provider boundary explicit. The default provider is `local`: starting Teddy does not require an account, an OpenAI API key, or cloud fallback. OpenAI remains available only when the operator explicitly starts with `TEDDY_PROVIDER=openai`.

## Local runtime contract

The local speech turn is `audio/wav -> ASR -> loopback LLM -> TTS -> NDJSON`. The browser captures bounded 16 kHz mono PCM/WAV and `/api/local/turn` emits state, transcript, text, audio and completion events. TTS audio is decoded through the same Web Audio analyser used by the existing expression rig, so local speech continues to drive Teddy's mouth and presence.

The control plane fails closed. Without `TEDDY_ASR_COMMAND` and `TEDDY_TTS_COMMAND`, local turns return `503 local_engines_not_configured`. The LLM endpoint is constrained to plain HTTP loopback and defaults to `http://127.0.0.1:8080`; there is no automatic request to OpenAI after a local failure.

Typical native integration variables are:

```bash
export TEDDY_PROVIDER=local
export TEDDY_ASR_COMMAND=/path/to/asr-wrapper
export TEDDY_ASR_ARGS='[]'
export TEDDY_LLAMA_URL=http://127.0.0.1:8080
export TEDDY_TTS_COMMAND=/path/to/tts-wrapper
export TEDDY_TTS_ARGS='[]'
./teddy.sh
```

ASR wrappers receive the temporary WAV path as their final argument and write UTF-8 transcript text to stdout. TTS wrappers receive temporary text and output-WAV paths as their final two arguments. Child processes use `shell:false`, bounded stdout and abort-driven termination.

## Artifact boundary

v0.7 includes an atomic artifact primitive requiring HTTPS, exact expected size, SHA-256 and license metadata. Partial downloads are never promoted. This PR intentionally does **not** claim that a production-quality ASR/LLM/TTS weight bundle is vendored: native engines and weights remain an operator-provided boundary until a complete pinned model manifest is committed and tested on supported platforms.

## Verification

Physical tests cover real child-process spawning/cancellation, output bounds, a real loopback HTTP mock for the LLM contract, local-service fail-closed behavior, WAV encoding and fragmented NDJSON. A deterministic semantic mutation campaign additionally evaluates exactly 1,000,000 seeded identities: 250,000 typical, 250,000 atypical, 250,000 challenging and 250,000 adversarial mutations.

The mutation campaign is a contract-level falsification harness, not one million paid model sessions and not one million full AST rewrites. CI regenerates its report from the checked-out sources and requires zero critical survivors and zero unsafe outcomes.
